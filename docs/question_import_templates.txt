ExamiQ Question CSV Import — Column Guide
=========================================

Required columns (row 1 header):
  subject_code, topic_name, difficulty, question_type, stem,
  choice_a, choice_b, choice_c, choice_d, correct_label, expected_answer,
  concept_tag, explanation_step_1, explanation_step_2, explanation_step_3,
  status, is_active

Shared rules
------------
- subject_code must match the course subject you import into (e.g. BSEM 22).
- topic_name must already exist under that subject in ExamiQ.
- difficulty: easy | medium | hard
- question_type: mcq (Multiple Choice only)
- status: approved (recommended)
- is_active: true | false
- Wrap fields that contain commas in double quotes.
- Fill choice_a–choice_d and correct_label (A–D). Leave expected_answer empty for MCQ.
